# Софи — сайт салона красоты

Статический сайт: Нижний Новгород, Большая Покровская улица, 71А, 3 этаж.

## Файлы
- `index.html` — страница и тексты
- `styles.css` — оформление (цвета — в начале файла, блок `:root`)
- `config.js` — **все номера телефонов** (запись к парикмахерам, на ногти, в VIP-зал, вакансии)
- `script.js` — окна записи и отклика на вакансию (услуги для каждого направления — в начале файла, блок `FLOWS`)

## Как поменять номер
Откройте `config.js` и заполните нужную строку, например:

```js
hair: { display: "+7 (999) 123-45-67", tel: "+79991234567", whatsapp: "79991234567", telegram: "" },
```

Как работает запись: клиент нажимает «Записаться» → выбирает услугу → вводит имя, телефон, дату и время →
получает готовый текст заявки и кнопки «Отправить в WhatsApp» / «Отправить в Telegram» / «Позвонить»
(показываются только заполненные). Пока ничего не заполнено, в окне написано «Номер для связи скоро появится».
